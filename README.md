# mam-engine

A custom graphics engine developed as a final-year university project by a team of three developers. The engine was designed with a modular architecture and supports both OpenGL and Vulkan rendering backends.

## My Contributions

- Contributed to the overall architecture and development of the rendering engine.
- Designed and implemented the OpenGL rendering pipeline, including graphics resource management, render state handling, and draw-call submission.
- Developed a modular material and shader system using C++ templates and abstraction layers, enabling reusable and configurable rendering workflows.
- Designed and implemented the engine's UI system architecture, managing component lifecycles and render-order dependencies through RAII-based patterns.
- Implemented and maintained the render pass framework used to organize rendering operations and dependencies.
- Developed and integrated several graphics techniques, including Deferred Rendering and Deferred Lighting.
