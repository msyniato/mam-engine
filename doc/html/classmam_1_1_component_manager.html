Detailed Description

Manages all component types and their storage.

The ComponentManager is responsible for:

  • Registering component types
  • Assigning a unique ComponentType ID to each component
  • Storing and retrieving component arrays
  • Adding, removing, and accessing components for entities

Internally, each component type is stored inside a ComponentArray<T>, which provides dense storage for cache-efficient iteration.
