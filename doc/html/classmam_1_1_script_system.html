Detailed Description

System responsible for executing Lua scripts attached to entities.

ScriptSystem manages the lifecycle of scripts, including:

  • Initializing the Lua environment
  • Binding the engine API to Lua
  • Executing script update functions each frame
  • Ensuring scripts are loaded and initialized for each entity
