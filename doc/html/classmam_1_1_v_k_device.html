Detailed Description

Vulkan implementation of the GraphicDevice interface.

This class manages the Vulkan rendering backend including:

  • Vulkan instance and logical device
  • Swap chain creation and recreation
  • Render pass and framebuffers
  • Command buffers and synchronization
  • GPU buffers
  • Frame rendering
