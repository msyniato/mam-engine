Detailed Description

Manages creation, destruction, and signatures of entities.

The EntityManager is responsible for:

  • Assigning unique entity IDs
  • Recycling destroyed entity IDs
  • Storing component signatures for each entity

Other ECS managers use these signatures to determine which systems should process an entity.
