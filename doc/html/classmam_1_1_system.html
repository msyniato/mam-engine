Detailed Description

Base class for all ECS systems.

Systems define behavior that operates on entities with specific components. Each derived system stores the set of entities it currently processes.

std::set<Entity> mam::System::entities_

Set of entities currently managed by the system.

The ECS coordinator updates this set whenever an entity's component signature matches (or no longer matches) the system's required signature.
