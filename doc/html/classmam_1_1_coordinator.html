Detailed Description

Central interface of the ECS framework.

The Coordinator acts as a façade that connects the three main ECS managers:

  • EntityManager
  • ComponentManager
  • SystemManager

It provides a unified API for creating entities, managing components, and registering systems. Game code typically interacts only with this class rather than directly with the individual managers.
