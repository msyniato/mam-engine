Detailed Description

Manages all ECS systems and their signatures.

SystemManager is responsible for:

  • Registering systems
  • Storing system signatures (component requirements)
  • Providing access to system instances
  • Handling entity destruction

Each system has a signature representing the combination of components required for entities to belong to it.
