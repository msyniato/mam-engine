\doxysubsection{Detailed Description}
Manages creation, destruction, and signatures of entities. 

The \mbox{\hyperlink{classmam_1_1_entity_manager}{Entity\+Manager}} is responsible for\+:
\begin{DoxyItemize}
\item Assigning unique entity I\+Ds
\item Recycling destroyed entity I\+Ds
\item Storing component signatures for each entity
\end{DoxyItemize}

Other E\+CS managers use these signatures to determine which systems should process an entity.
