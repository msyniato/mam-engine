\doxysubsection{Detailed Description}
Vulkan implementation of the \mbox{\hyperlink{classmam_1_1_pipeline2}{Pipeline2}} interface. 

This class manages Vulkan graphics pipeline creation, shader management, descriptor sets, uniform buffers, and render pass execution.
