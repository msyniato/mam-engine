\doxysubsection{Detailed Description}
Central interface of the E\+CS framework. 

The \mbox{\hyperlink{classmam_1_1_coordinator}{Coordinator}} acts as a façade that connects the three main E\+CS managers\+:


\begin{DoxyItemize}
\item \mbox{\hyperlink{classmam_1_1_entity_manager}{Entity\+Manager}}
\item \mbox{\hyperlink{classmam_1_1_component_manager}{Component\+Manager}}
\item \mbox{\hyperlink{classmam_1_1_system_manager}{System\+Manager}}
\end{DoxyItemize}

It provides a unified A\+PI for creating entities, managing components, and registering systems. Game code typically interacts only with this class rather than directly with the individual managers.
