\doxysubsection{Detailed Description}
\mbox{\hyperlink{classmam_1_1_system}{System}} responsible for rendering entities with meshes. 

Processes all entities with \mbox{\hyperlink{structmam_1_1_render_component}{Render\+Component}} and \mbox{\hyperlink{structmam_1_1_transform_component}{Transform\+Component}} and submits them to the rendering pipeline.
