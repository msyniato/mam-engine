\doxysubsection{Detailed Description}
Descriptor structure used to configure a Vulkan graphics pipeline. 

This structure groups all Vulkan pipeline state objects required during pipeline creation. It acts as an intermediate container to configure vertex input, rasterization, viewport, blending, and shader stages before creating the final Vulkan pipeline.
