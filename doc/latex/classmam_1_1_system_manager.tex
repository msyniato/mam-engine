\doxysubsection{Detailed Description}
Manages all E\+CS systems and their signatures. 

\mbox{\hyperlink{classmam_1_1_system_manager}{System\+Manager}} is responsible for\+:
\begin{DoxyItemize}
\item Registering systems
\item Storing system signatures (component requirements)
\item Providing access to system instances
\item Handling entity destruction
\end{DoxyItemize}

Each system has a signature representing the combination of components required for entities to belong to it.
