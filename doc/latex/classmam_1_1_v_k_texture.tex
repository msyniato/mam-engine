\doxysubsection{Detailed Description}
Vulkan implementation of the \mbox{\hyperlink{classmam_1_1_texture}{Texture}} interface. 

This class provides a Vulkan-\/backed texture object that implements the generic \mbox{\hyperlink{classmam_1_1_texture}{Texture}} interface used by the engine. It handles creation of Vulkan images, memory allocation, texture data uploads, sampler configuration, and binding to descriptor slots.
