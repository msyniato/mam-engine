\doxysubsection{Detailed Description}
\mbox{\hyperlink{classmam_1_1_system}{System}} responsible for processing lights in the scene. 

Collects and updates all entities with \mbox{\hyperlink{structmam_1_1_light_component}{Light\+Component}}, applies lighting calculations, and submits the data to the renderer.
