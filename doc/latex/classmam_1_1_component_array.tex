\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename T$>$\newline
class mam\+::\+Component\+Array$<$ T $>$}

Dense storage container for components of type T. 

Stores components in a packed array to maintain cache-\/friendly iteration. Entity-\/to-\/index and index-\/to-\/entity maps are used to efficiently insert, remove, and access components in O(1) time.

When a component is removed, the last element in the array is moved into the removed slot (swap-\/remove technique) to maintain dense storage.
