\doxysubsection{Detailed Description}
Manages all component types and their storage. 

The \mbox{\hyperlink{classmam_1_1_component_manager}{Component\+Manager}} is responsible for\+:
\begin{DoxyItemize}
\item Registering component types
\item Assigning a unique Component\+Type ID to each component
\item Storing and retrieving component arrays
\item Adding, removing, and accessing components for entities
\end{DoxyItemize}

Internally, each component type is stored inside a Component\+Array$<$\+T$>$, which provides dense storage for cache-\/efficient iteration.
