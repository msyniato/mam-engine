\doxysubsection{Detailed Description}
\mbox{\hyperlink{classmam_1_1_system}{System}} responsible for executing Lua scripts attached to entities. 

\mbox{\hyperlink{classmam_1_1_script_system}{Script\+System}} manages the lifecycle of scripts, including\+:
\begin{DoxyItemize}
\item Initializing the Lua environment
\item Binding the engine A\+PI to Lua
\item Executing script update functions each frame
\item Ensuring scripts are loaded and initialized for each entity 
\end{DoxyItemize}
